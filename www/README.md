# 🎉 MVP Sistema de Gestión de Cooperativas - ACA

## ✅ ¡LISTO PARA USAR CON LIVE SERVER!

### 🚀 Cómo ejecutar el MVP:

1. **Abrir VS Code** en la carpeta: `cooperativas-admin/www`

2. **Instalar Live Server** (si no lo tienes):
   - Ve a Extensions (Ctrl+Shift+X)
   - Busca "Live Server" de Ritwick Dey
   - Instalar

3. **Ejecutar con Live Server**:
   - Click derecho en `index.html`
   - Seleccionar "Open with Live Server"
   - O presionar Alt+L Alt+O

4. **Acceder**: Se abrirá automáticamente en tu navegador (generalmente `http://127.0.0.1:5500`)

### 👤 **Usuarios de Prueba:**

| Rol | Usuario | Contraseña | Permisos |
|-----|---------|------------|----------|
| **Admin ACA** | `admin_aca` | `admin123` | ✅ Ver todas las cooperativas<br>✅ Acceso total al sistema |
